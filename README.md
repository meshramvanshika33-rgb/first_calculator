🧮 Basic Calculator

A simple and responsive Basic Calculator built using **Python**, **Flask**, **HTML**, and **CSS**. This project performs basic arithmetic operations through a clean and user-friendly web interface.


🔗 **Live Website:**
https://first-calculator-5.onrender.com

📌 Features

➕ Addition
➖ Subtraction
✖️ Multiplication
➗ Division
🎨 Clean and responsive user interface
⚡ Flask backend with HTML/CSS frontend
🌐 Deployed on Render

🛠️ Technologies Used

* Python
* Flask
* HTML5
* CSS3
* Render

⚙️ Installation

1. Clone the repository

```bash
https://github.com/meshramvanshika33-rgb/first_calculator.git
```

2. Navigate to the project directory

```bash
cd first_calculator
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Run the application

```bash
python app.py
```

5. Open your browser and visit

```text
http://127.0.0.1:5000
```
