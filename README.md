🧮 Basic Calculator

A simple and responsive Basic Calculator built using **Python**, **Flask**, **HTML**, and **CSS**. This project performs basic arithmetic operations through a clean and user-friendly web interface.

🚀 Live Demo

🔗 **Live Website:**
https://first-calculator-5.onrender.com

📌 Features

➕ Addition
➖ Subtraction
✖️ Multiplication
➗ Division
🎨 Clean and responsive user interface
⚡ Flask backend with HTML/CSS frontend
🌐 Deployed on Render

🛠️ Technologies Used

* Python
* Flask
* HTML5
* CSS3
* Render

⚙️ Installation

1. Clone the repository

```bash
git clone PASTE_YOUR_GITHUB_REPO_LINK_HERE
```

2. Navigate to the project directory

```bash
cd repository-name
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Run the application

```bash
python app.py
```

5. Open your browser and visit

```text
http://127.0.0.1:5000
```
